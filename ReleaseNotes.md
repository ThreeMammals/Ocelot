## Pre-release 3 for [.NET 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) SDK (version [{0}](https://www.nuget.org/packages/Ocelot/{0}))
> Milestone: [.NET 10](https://github.com/ThreeMammals/Ocelot/milestone/13)

This is **Pre-release 3** for the [.NET 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) SDK.

Version [{0}](https://www.nuget.org/packages/Ocelot/{0}) includes upgraded solutions and [NuGet packages](https://www.nuget.org/profiles/ThreeMammals) based on .NET SDK [10.0.300](https://dotnet.microsoft.com/en-us/download/dotnet/10.0), released on May 12, 2026. For more details about SDK [10.0.300](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) (Runtime [10.0.8](https://github.com/dotnet/core/blob/main/release-notes/10.0/10.0.8/10.0.8.md)), see the [Release notes](https://github.com/dotnet/core/blob/main/release-notes/10.0/10.0.8/10.0.8.md).

Development teams can start migrating their Ocelot-based projects using this [Beta 3](https://www.nuget.org/packages/Ocelot/{0}) release to upgrade to the [.NET 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) SDK with Long-Term Support (LTS).
